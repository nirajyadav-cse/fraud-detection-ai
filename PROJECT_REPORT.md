# Project Report: AI Fraud Detection in Financial Transactions

## Problem statement
This project demonstrates a machine-learning workflow that estimates which transaction-like records may need review.

## Objectives
- Create a reproducible classification pipeline.
- Train a Random Forest model.
- Provide a Streamlit interface for CSV uploads.
- Export predictions for further review.

## Dataset
The training data is synthetic and generated by `train_model.py`. It is not a real bank dataset.

## Features
`amount`, `time`, `merchant_risk`, `distance_from_home_km`, `failed_attempts_24h`, and `is_international`.

## Methodology
1. Generate synthetic rows and labels.
2. Split data into training and test subsets.
3. Fit a scikit-learn pipeline with median imputation and a Random Forest classifier.
4. Print classification metrics on synthetic hold-out data.
5. Save the model and feature list.
6. Load the saved model in Streamlit to score uploaded CSV rows.

## Limitations and ethics
Synthetic data is not representative of real financial activity. This model is not suitable for real transaction blocking or customer decisions. Production use would require appropriate data, validation, security, privacy controls, monitoring, and human review.

## Conclusion
The project demonstrates data generation, model training, evaluation, model saving, and an interactive dashboard.
